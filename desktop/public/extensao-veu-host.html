EXTENSÃO · 0.3.7

Véu Host

Liga o SO veu.ch8ai.com.br ao seu Chrome/Edge: ChatGPT/Claude/Grok (assinatura), WhatsApp Web (QR), Agenda, arquivos.

baixar veu-host-0.3.7.tar.gz manifest.json

Instalar (Chrome / Edge)

  1. Baixe e descompacte o .tar.gz numa pasta fixa
  2. Abra chrome://extensions (ou edge://extensions)
  3. Ative Modo do desenvolvedor
  4. Carregar sem compactação → selecione a pasta descompactada (a que tem manifest.json)
  5. Volte em veu.ch8ai.com.br e dê F5 — topo deve mostrar host · ok

Já tinha uma versão antiga?

Em chrome://extensions clique em Recarregar na Véu Host, ou remova e carregue de novo a pasta 0.3.7.

Host nativo (opcional · terminal/arquivos)

Pasta native/ no pacote — install.sh (Linux/Mac) ou install.cmd (Windows) com o ID da extensão.
