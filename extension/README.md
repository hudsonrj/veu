# Véu Host 0.3.2

1. Carregar esta pasta em `chrome://extensions` (sem compactação)
2. Copiar o **ID** da extensão
3. Native host (terminal):
   - Windows: `native\install.ps1 -ExtensionId <ID>`
   - Linux/macOS: `native/install.sh <ID>`
4. Abrir https://veu.ch8ai.com.br → F5 → host · ok → abrir terminal
